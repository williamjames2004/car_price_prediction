Project Overview

A Data-Driven Approach to Car Pricing

AutoValue is a machine learning web application that predicts a vehicle's estimated price from its technical and performance characteristics.

Project Objective

Train a regression model to learn relationships between car specifications and historical prices.

Dataset Processing

Handle missing values, scale numerical features and encode categorical features before training.

Price Prediction

Submit vehicle specifications through a form and obtain an estimated price from the saved model.

How It Works

The application sends your inputs to a trained Support Vector Regression pipeline. The pipeline preprocesses the values and predicts the price using patterns learned from data.csv.

Machine Learning

Support Vector Regression

Support Vector Regression (SVR) is a supervised learning algorithm for predicting continuous values. This project uses an RBF kernel to model nonlinear relationships between vehicle specifications and price.

01

Feature Selection

Select 16 columns that describe vehicle risk rating, fuel, body, drivetrain, dimensions, engine characteristics and fuel economy.

02

Missing-Value Imputation

SimpleImputer fills missing numerical values with the median and categorical values with the most frequent category.

03

Numerical Feature Scaling

StandardScaler transforms numerical values using statistics learned from the training data. This is important because SVR uses distances between transformed observations.

04

One-Hot Encoding

OneHotEncoder converts categories such as fuel type, car body and engine type into numeric indicators. Unknown categories are ignored during prediction.

05

RBF Kernel

The Radial Basis Function kernel allows SVR to model nonlinear relationships. It calculates similarities between observations in the transformed feature space.

06

Evaluation and Training

The script evaluates a train/test split using MAE and R², then fits the final pipeline on all valid records and saves it to car_price_model.pkl.

Evaluation Metrics

Mean Absolute Error (MAE) measures the average absolute difference between actual and predicted prices. Lower values indicate smaller errors.

R² Score measures how well predictions explain the variation in the target. A value closer to 1 is generally desirable, although negative values are possible.

Why Use an RBF Kernel?

Car prices do not always change linearly with engine size, weight, horsepower and fuel economy. The RBF kernel helps the model learn more complex relationships than a simple linear regression.

Understanding the Parameters

C=100 controls the penalty associated with errors outside the epsilon margin. epsilon=0.1 defines the margin in the target's price units. These values are fixed in the current implementation; they have not necessarily been optimized for the dataset.

Frequently Asked Questions

Questions About AutoValue

Learn more about the prediction process, algorithm and limitations of this project.

What is Support Vector Regression?

SVR is a supervised machine learning algorithm that predicts continuous numerical values. It attempts to fit predictions within a chosen error margin while controlling model complexity.

Why is feature scaling important?

Numerical features use different scales. StandardScaler transforms them using training statistics, which helps the RBF kernel compare observations more appropriately.

Is the predicted price guaranteed?

No. The result is a statistical estimate learned from historical data. It is not a live market quote or a guaranteed selling price.

Which features does the model use?

Symboling, fueltype, aspiration, carbody, drivewheel, wheelbase, carlength, carwidth, curbweight, enginetype, cylindernumber, enginesize, boreratio, horsepower, citympg and highwaympg.

What if I select an unseen category?

OneHotEncoder is configured to ignore unknown categories. However, predictions for categories not represented during training may be less reliable.

How can the model be improved?

Use representative data, tune SVR parameters with cross-validation, compare alternative regression algorithms and evaluate results on data that was not used for training.
